# Cyrbyte Security

Single-page static website for `security.cyrbyte.com`.

## Deploy on Vercel

1. Create a new Vercel project from this folder/repository.
2. Framework preset: **Other**.
3. Build command: leave blank.
4. Output directory: leave blank.
5. Add custom domain: `security.cyrbyte.com`.

Contact links currently use `info@cyrbyte.com`.
